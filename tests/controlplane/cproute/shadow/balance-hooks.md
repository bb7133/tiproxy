# Group.Balance hook checkpoint (C1)

Run `bash tests/controlplane/cproute/shadow/balance-hooks-run.sh` with the pinned Go and Rust toolchains. The existing `make controlplane-cproute-native-evidence` entrypoint also runs it, alongside its unchanged native faults and sustained windows.

The private construction path invokes the real Group.Balance and concrete native policy. It captures the actual backend iteration, original clock and keyspace strings, original context results, physical visits and redirect outcomes. Native leases belong to the parent before policy input copying. An unconditional defer cleans both sealed and interrupted children before Group unlock; successful publication transfers all leases to the writer.

The Go fixture exports its complete original lifecycle/native prefix, three actual Balance calls (refusal, acceptance, pending/cooldown skips and zero), and final settlement. `balance_hook_check` strictly decodes the Go frames and independently compares each caller. A separate replay corrupts only the final accepted count and checks that qualification becomes Invalid while ledger, compared sequence, factor lifetime and retained native bytes remain unchanged. This executable is test-only; production consumer dispatch is unchanged.

The mutation catalog contains 14 compiling faults: standalone child allocation, double native publication, normal-only cleanup, cleanup after unlock, forgotten unsealed child ownership, release at admission, omitted context capture, context after nil, quota before context, omitted closing visits, false callback recorded as true, skipped callback recorded as false, reversed direct keyspace strings, and capacity truncating the real scan. Each names its targeted test/assertion. Compile failures and failures outside that assertion are rejected. All mutations operate in an isolated source copy; source hashes, compile logs, executable hashes/timestamps, run logs and restored baseline results are retained under `CP_ROUTE_BALANCE_HOOK_EVIDENCE` (or the printed temporary evidence directory).

Go tests additionally cover distinct whole-pair/direct keyspace reads, cancellation, writer retention, the existing native-only factory, and an actual divide-by-zero panic. The unsealed-child test places a contender on the real Group mutex and inspects invalidation and released records immediately after it acquires the lock. Capacity testing scans 66 real connections, proving that overflow at the 65th captured visit cannot shorten the production scan.

This checkpoint does not install scheduler or selection capabilities. Route/selector, router pass and consumer dispatch, failover/close hooks, fresh factory binding and all full 2B2 qualification windows remain separate work. These fixtures do not count toward sustained outcome minima.
